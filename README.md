# Sforzato Music — Landing Page "En Tu Memoria"

Página web de lanzamiento para el álbum musical cristiano **"En Tu Memoria"** producido por **Sforzato Music** (*"Impulsando música con propósito."*).

---

## 📌 Estado del Proyecto
- **Fase Actual:** Fase 1 — Inicialización y Estructura Base (`output: 'export'`).
- **Framework:** Next.js (App Router, Static Export, TypeScript, ESLint).
- **Repositorio:** `https://github.com/israelandreslagosrocha-jpg/SFORZATO`

---

## 🚀 Comandos de Desarrollo

```bash
# Servidor de desarrollo local
npm run dev

# Validación de tipos y linter
npm run lint

# Exportación estática (SSG)
npm run build
```
